# FreedomPlus v1.3.9

## 修复

- 修复抖音 40.8.0 运行约一分钟后触发的 `PagerAdapter` 计数异常崩溃。
- 修复方式：信息流过滤改到 Adapter 数据落表阶段，并同步清理同源平行列表，保证 `getCount()`、`getItem()` 与页面索引一致。
- 增加仅针对 PagerAdapter 数量失配异常的兜底刷新，避免滚动结束回调中的残余失配直接终止进程。

## 真机验证

本版本已在**小米手机**完成真机验证。

其他品牌手机的系统实现、权限策略和厂商定制可能不同，需自行测试。
